KI-gestützter Styling-Berater mit Gamification - Dein persönlicher Style-Assistent für professionelles Auftreten.

== Description ==

StyleGenius Pro ist ein umfassendes WordPress-Plugin, das KI-gestützte Styling-Beratung mit einem motivierenden Gamification-System verbindet. Perfekt für Business-Stylisten, Mode-Berater und alle, die ihren professionellen Stil verbessern möchten.

= Hauptfunktionen =

**KI-Styling-Beratung**
* Text-basierte Beratung mit Claude AI oder OpenAI
* Personalisierte Empfehlungen basierend auf deinem Profil
* Foto-Analyse für Kleidungsstücke und Outfits

**Style-Quiz**
* Ermittle deinen Style-Typ mit 7-10 Fragen
* 6 verschiedene Style-Typen
* Teilbare Badge-Grafik als Ergebnis

**Virtuelle Garderobe**
* Kleidungsstücke fotografieren und kategorisieren
* KI-generierte Outfit-Kombinationen
* "Outfit des Tages" Generator
* Lücken-Analyse

**Farb- & Typberatung**
* Selfie-Analyse für Farbtyp-Bestimmung
* Persönliche Farbpalette
* Metall-Empfehlung (Gold/Silber)

**Saisonale Capsule Wardrobes**
* KI-generierte Capsule aus vorhandener Garderobe
* 30-Tage-Outfit-Plan
* Mix & Match Grid

**Gamification**
* Punkte-System mit 10 Level
* Über 40 Badges in verschiedenen Kategorien
* Streak-System für tägliche Aktivität
* Leaderboards und Challenges

**Social Features**
* Referral-System mit gestaffelten Rewards
* Social Sharing für alle Plattformen
* Weekly Style Challenges mit Community-Voting

= Subscription-Tiers =

* **Free:** 10 KI-Anfragen pro Monat
* **Premium (€9,90/Monat):** 100 Anfragen, erweiterte Features
* **VIP (€29,90/Monat):** Unbegrenzt, Shopping-Assistent, alle Features

= Integrationen =

* WooCommerce Subscriptions für Zahlungen
* Elementor Widgets
* Affiliate-Integration: Zalando, AboutYou, Amazon

== Installation ==

1. Plugin-Ordner nach `/wp-content/plugins/` hochladen
2. Plugin im WordPress-Admin aktivieren
3. Unter "StyleGenius" → "Einstellungen" die API-Keys eintragen
4. WooCommerce Subscription-Produkte werden automatisch erstellt

== Frequently Asked Questions ==

= Welche AI-Provider werden unterstützt? =

StyleGenius Pro unterstützt sowohl Claude (Anthropic) als auch OpenAI. Du kannst in den Einstellungen wählen, welchen Provider du verwenden möchtest.

= Ist das Plugin DSGVO-konform? =

Ja! Nutzer können alle ihre Daten einsehen, exportieren und löschen. Privacy-Einstellungen erlauben die Kontrolle über öffentliche/private Felder.

= Benötige ich WooCommerce? =

Ja, WooCommerce wird für das Subscription-System benötigt. WooCommerce Subscriptions wird für wiederkehrende Zahlungen empfohlen.

= Kann ich das Plugin auf Deutsch verwenden? =

Das Plugin ist komplett auf Deutsch! Alle Texte, Prompts und Benutzeroberflächen sind in deutscher Sprache.

== Privacy ==

StyleGenius Pro speichert folgende Daten:
* Benutzerprofile und Präferenzen
* Hochgeladene Fotos (verschlüsselt gespeichert)
* Chat-Verläufe mit der KI
* Gamification-Daten (Punkte, Badges, etc.)

Alle Daten können vom Benutzer eingesehen, exportiert und gelöscht werden.
Bei Verwendung der KI-Features werden Daten an Claude (Anthropic) oder OpenAI übermittelt.
